## 一、任务理解

把**别人的分享链接**里的视频，分批"中转"进你的个人云盘，为每个视频生成**一条独立分享链接**交付给你；
每批做完等你确认，再清空中转区做下一批，直到源链接里的视频全部处理完。

| 项 | 内容 |
|---|---|
| 源 | `https://mega.nz/folder/I7EUnZ7Q#dXEScojKVZRvZW67oWyVfg`（他人分享的文件夹链接） |
| 中转站 | 你的个人云盘（只做临时存放，**用完即删**） |
| 交付物 | 每个视频一条 `https://mega.nz/file/...#...` 链接 |
| 硬约束 | 云盘容量有限，必须分批；每批不超过预算 |
| 防重 | 维护「已存文件列表」，已处理过的源文件不再重复导入 |
| 节奏 | 每批交付后**停下等你指令**，你说"下一轮"我才继续 |

## 二、已从源码验证的关键技术事实

这几条决定了方案能不能成立，我都已在 `~/MEGAcmd` 源码里查证：

### 1. `mega-import` 可以只导入文件夹链接里的**单个文件** ✅
`src/megacmdcommonutils.cpp:127` 的 `getPublicLinkHandle()` 明确解析两种深层链接：
- `https://mega.nz/folder/<句柄>#<密钥>/file/<文件句柄>` → 定位**单个文件**
- `https://mega.nz/folder/<句柄>#<密钥>/folder/<子文件夹句柄>` → 定位子文件夹

**这是整个方案的基础**——否则只能整包导入，大文件夹根本放不下。

### 2. 导入过程**不需要登出你的个人账号** ✅
`src/megacmdexecuter.cpp:9934` 起：文件夹链接是用**独立的辅助 API 实例**（`apiFolder_0..4`）登录的，
并 `setAccountAuth()` 借用你的账号凭据，最后用 `api->copyNode()` 在**服务端直接复制**。

所以：**你的个人账号全程保持登录**，不用来回切换。（上一轮我担心的"只能同时登录一个"不适用于 import。）

### 3. 服务端复制，不消耗本机带宽 ✅
`copyNode` 是 MEGA 服务器内部搬运，数据不经过本机。速度取决于 MEGA，通常很快。

### 4. 删除必须**二次操作**才真正释放空间 ⚠️
`rm` 只是把文件移进**回收站**，而回收站**照样占容量**（`mega-df` 里单列一项）。
必须再删一次 `//bin` 里的对应节点才会永久删除。
→ 清空动作固定为两步：`mega-rm -r -f <路径>` ⇒ `mega-rm -r -f //bin/<名字>`

### 5. 删文件 = 分享链接立即失效 ⚠️⚠️
分享链接指向的就是那个文件本身。**你把链接转存/下载完之前，我绝不能删。**
这也是"等你确认再清空"这个节奏存在的根本原因。

## 五、目录与状态文件设计

### 中转区隔离（安全设计）
所有导入文件一律放进**专用顶层目录** `/staging/`。
删除操作**只允许作用于 `/staging/` 和 `//bin`**，绝不触碰你原有的 `/all/...`。

### `work/state/processed_files.tsv`（已存文件列表）

| 字段 | 含义 |
|---|---|
| `name` | 文件名 |
| `size_bytes` | 字节数（防重键之一） |
| `source_path` | 源内完整路径 |
| `source_handle` | 源文件句柄（最精确的去重键） |
| `source_ref` | 来源标识（哪个链接/哪一轮） |
| `batch` | 批次号 |
| `status` | `done` / `imported` / `failed` / `skipped` |
| `output_link` | 交付的分享链接 |
| `processed_at` | 处理时间 |

去重规则：**`source_handle` 精确匹配** 优先；跨来源时回退用 **`name` + `size_bytes`** 匹配。

另设 `work/state/round_log.md` 记录每轮动作流水，出问题可回溯。

## 六、风险与对策

| 风险 | 后果 | 对策 |
|---|---|---|
| 误删你不想删的文件 | 数据丢失 | **只允许删除**：(a) `/staging/` 下我导入的文件，(b) 「已存文件列表」里登记过的文件；删除前先打印完整清单 |
| 删早了，链接作废 | 你拿不到文件 | 严格等你"下一轮"指令才删 |
| 回收站没清，空间没释放 | 下一批导入失败 | 固定两步删除 + `mega-df` 复核 |
| `mega-import` 深层链接在你这个版本不生效 | 方案不成立 | 阶段 0 先用 1 个小文件实测；不行则降级为「整包导入后裁剪」或「本机下载再上传」 |
| 单个视频大于可用空间 | 永远装不下 | 提前算出来单独告诉你，不硬试 |
| 免费账号导入配额受限 | 中途报错 | 阶段 0 实测；受限则减小批次、加延时重试 |
| 源链接被撤销/失效 | 任务中断 | 状态文件支持断点续做，已完成的链接不受影响 |
| 我再次误操作危险命令 | 灾难 | **命令白名单**：只用 `import/export/ls/find/df/mkdir/rm/transfers/whoami`；`mega-cancel`、`mega-passwd`、`mega-confirmcancel` 等一律不碰 |
